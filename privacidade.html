Política de privacidade

Última atualização: 27 de outubro de 2026.

O Battu Studio AI ("Battu") é um aplicativo que roda no computador do próprio usuário. Esta política explica quais dados ele acessa e o que faz com eles.

Dados acessados

  • YouTube (Google): nome, identificador, foto e lista de vídeos do canal autorizado, e permissão para enviar vídeos ao canal.
  • Instagram e Facebook (Meta): nome e foto da Página e da conta profissional do Instagram autorizadas, e permissão para publicar vídeos nelas.
  • TikTok: nome de exibição, foto e identificador da conta autorizada, e permissão para publicar vídeos nela.

Como os dados são usados

Somente para mostrar ao usuário qual conta está conectada e para enviar os vídeos que ele aprovou ou que seguem regras configuradas por ele. O Battu não vende, não compartilha e não usa esses dados para publicidade.

Onde os dados ficam

As credenciais de acesso ficam criptografadas no próprio computador do usuário (cofre do Windows). Não há servidor do Battu recebendo esses dados. Os vídeos são enviados diretamente do computador do usuário para a rede escolhida.

Uso de dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado. O Battu usa os Serviços de API do YouTube; ao conectar um canal você também concorda com os Termos de Serviço do YouTube e com a Política de Privacidade do Google.

Como remover o acesso

No Battu, use "Desconectar" na conta. Para revogar no serviço: Google em myaccount.google.com/permissions; Meta em Configurações › Integrações comerciais; TikTok em Configurações › Segurança › Apps com permissão. Ao desconectar, a credencial local é apagada.
